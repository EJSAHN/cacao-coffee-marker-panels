## Short description

Reproducible Python pipeline for identity-aware genomic prediction and low-density SNP panel evaluation in public cacao and coffee breeding datasets.

## Long description

This repository provides a reproducible workflow for integrating public cacao and coffee genotype–phenotype resources. It harmonizes source-specific genotype and phenotype files, audits marker quality, germplasm identity, and population structure, compares random five-fold and genetic cluster-out validation, benchmarks full-marker prediction models, and evaluates low-density SNP panels selected within training folds. The workflow produces public-facing tabular outputs and a multi-sheet analysis workbook; raw public datasets are not redistributed.
